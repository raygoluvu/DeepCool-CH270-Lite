# 九州風神 CH270 機箱數顯精簡獨立驅動（DeepCool CH270 Lite）

超輕量、完全自包含、開箱即用的**九州風神 CH270 機箱數顯控制系統**。徹底告別官方體積龐大（數百 MB）、常駐耗用資源的 Electron 臃腫套件！

---

## ✨ 核心功能

- ⚡ **原生輕量**：以原生 C# WinForms 與底層 Win32 API 建構，總大小僅數 MB，CPU 與記憶體占用極低。
- 📦 **開箱即用**：無須預先安裝或解除安裝九州風神官方軟體；內建完整的底層感應器橋接驅動，解壓縮後雙擊即可點亮。
- 🖥️ **完整顯示模式**：
  - **CPU 模式**：即時輪播 CPU 溫度、功耗、使用率、即時睿頻與風扇轉速。
  - **GPU 模式**：即時顯示機箱 GPU 指標，包括顯示卡溫度、功耗、使用率與頻率。
  - **自動輪播（CYCLE）**：全自動輪流顯示 CPU 睿頻、CPU 風扇與 GPU 狀態。
- 🌡️ **溫度單位即時切換**：支援攝氏度（℃）與華氏度（℉）即時切換。
- 🌀 **自由選擇風扇探頭**：內建支援主機板多種風扇介面（例如 `CPUFANIN0`、`SYSFANIN`、`AUXFANIN3`），即時讀取實際轉速。
- 📁 **自由重新命名與路徑自適應**：支援將程式資料夾任意重新命名或移動位置，開啟時會自動同步路徑。
- 🛑 **完全結束、秒級反應**：結束後會釋放所有控制代碼與資源，不會鎖住資料夾，也不會自行重新啟動。

```text

```

## 🔨 編譯方式

本專案設計為**零開發環境相依**。Windows 10/11 內建了 .NET Framework 編譯器，**無須安裝 Visual Studio 或 .NET SDK**。

### 方法一：一鍵編譯（推薦）

直接雙擊專案目錄中的 **`build.bat`**，即可自動編譯並輸出兩個元件。

### 方法二：手動使用命令列編譯

在專案根目錄開啟 PowerShell 或 CMD：

```cmd
# 1. 編譯前端控制面板
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /optimize+ /out:CH270.exe CH270.cs

# 2. 編譯背景推送守護行程
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /optimize+ /out:CH270.Service.exe CH270.Service.cs
```

## 🚀 使用說明

1. 編譯或下載發行版後，雙擊執行 **`CH270.exe`**。
2. 首次執行會顯示提示視窗；點擊【確定】即可註冊並啟動底層感應器系統服務（僅首次需要一次 UAC 授權）。
3. 之後日常啟動、切換模式、調整溫度單位或風扇介面皆可即時生效，不會再次要求 UAC 權限。
4. 若要完全停止服務或移動資料夾，請在控制面板右上角點擊【完全結束】，即可釋放所有背景行程並結束程式。
